# MediFlow Authentication FAQ

## 1. How do I log in to MediFlow?

Users can log in through the MediFlow login page using their registered email address and password. After successful authentication, the backend returns a JWT token and user information.

## 2. What authentication method does MediFlow use?

MediFlow uses JSON Web Tokens (JWT) for authentication. After successful login, a token is generated and used to authenticate protected API requests.

## 3. How long is the login token valid?

The JWT token generated by the backend expires after 2 hours. Users need to authenticate again after the token expires.

## 4. How are user passwords stored?

MediFlow uses bcryptjs to compare passwords against securely hashed password values. Passwords are not stored as plain text.

## 5. What happens if I enter an incorrect password?

MediFlow returns an authentication error with the message "Invalid email or password". The same message is used when the email address does not match an existing account.

## 6. Can patients access doctor dashboard features?

No. MediFlow uses role-based authorization. Patient accounts cannot access protected doctor-only endpoints.

## 7. Can doctors access another doctor's appointments?

No. Doctor-specific appointment operations verify that the appointment belongs to the authenticated doctor.

## 8. What user roles are supported?

MediFlow defines three roles in its database:
- PATIENT
- DOCTOR
- ADMIN

The implemented public workflows primarily support patients and doctors. An admin dashboard is not currently implemented.

## 9. What happens if the authentication token is invalid or expired?

Protected endpoints require valid authentication. If the token is missing, invalid or expired, the user must authenticate again before accessing protected functionality.

## 10. Does MediFlow use role-based access control?

Yes. MediFlow uses JWT authentication and role-based middleware to restrict access to patient and doctor operations. It also checks resource ownership for doctor-specific operations.
